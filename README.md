# Directorio LiveOps

Directorio visual del equipo de LiveOps Soporte (fijos, supervisores suplentes, especialistas y los dos lotes de nuevos ingresos) y del equipo B2B, con foto, cargo y nivel de desempeño de cada persona.

- `equipo_liveops.html` — la página publicada como Artifact.
- `fetch_avatars.py` — script que descarga y recorta las fotos de perfil de Slack a 128x128 para embeberlas en la página.
- `avatar_datauris.json` / `avatars_small/` — fotos procesadas usadas para generar los `data:` URIs embebidos en el HTML.
